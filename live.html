    What runs live?

    Every run performs five-fold cross-fitting, three-fold inner model tuning, ensemble-weight learning and final fitting on 55 training participants. The selected participant stays held out. No saved prediction or weight is used.

    Raw EEG preprocessing and feature extraction were completed previously. The backend loads 1,050 covariance and 240 spectral features per participant. A full run can take several minutes. One run is allowed at a time.

    Scores are uncalibrated research outputs, not diagnostic probabilities. A new run may differ from the historical 78.57% cohort result.
